# 017.03 — Build Decision Model Zero, the exact nonlinguistic demonstration

- **Sequence:** 3 of 5
- **Target:** successor Decision Model package work
- **Status:** dispatch after 017.02
- **Issue effect:** successor work; not an Issue 017 acceptance criterion

## Objective

Ship the smallest executable object that demonstrates Decision Model's
computational identity without hiding preparation or test interpretation inside
language models or learned encoders.

## Demonstration contract

Begin with already-constituted mathematical objects:

```text
given:
    state omega
    admissible finite test T = {e_i}

return:
    {omega(e_i)}
```

For the first binary example:

```text
T = {e_0, e_1}
e_0 + e_1 = unit effect
result = (omega(e_0), omega(e_1))
```

The demonstration must make the test explicit, show the resulting normalized
distribution, and include at least one sharp deterministic case and one
non-sharp probabilistic case.

## Exclusions

Decision Model Zero contains no:

- natural-language input;
- text encoder or language model;
- learned decoder;
- grokking requirement;
- Event enactment;
- sampling or choice policy presented as evaluation;
- claim that Issue 017 alone supplies a complete generalized OT measurement
  calculus.

If the initial backend uses only the single-step transport identity from 017.01,
label the demonstration accordingly. Do not present a transport quotient as an
already-derived arbitrary state/test calculus.

## Launch artifacts

Produce:

1. one install-and-run command;
2. one deterministic example script or CLI invocation;
3. machine-readable output;
4. a short explanation of state, effect, test, and distribution;
5. tests pinning the example's numerical result;
6. a limitations section stating what remains unimplemented and unproved.

## Done when

A new user can install the package, run one command, inspect a typed test and its
result, reproduce the output deterministically, and understand both the
demonstrated claim and its scientific boundary in under five minutes.
