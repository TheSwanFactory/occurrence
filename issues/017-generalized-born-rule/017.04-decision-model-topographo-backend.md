# 017.04 — Add the Decision Model–topographo backend

- **Sequence:** 4 of 5
- **Target:** successor Decision Model package work
- **Depends on:** 017.01, 017.02, and 017.03
- **Status:** dispatch after the generic contract and zero demonstration exist
- **Issue effect:** successor work; not an Issue 017 acceptance criterion

## Objective

Connect Decision Model to certified `topographo` functionality through a thin
backend while preserving the distinction between generic resolver semantics and
the specific OT/Kraus-84 construction.

## Dependency and module boundary

The permitted direction is:

```text
decision_model backend -> public topographo API
```

The backend must not:

- copy canonical arithmetic from `topographo`;
- import verification scripts;
- make `topographo` depend on `decision_model`;
- equate `topographo.ssd.fixed_head.readout_probability` with the OT-II
  transport quotient;
- relabel a single transition identity as a complete measurement calculus.

The module boundary is:

```text
decision_model.backends.topographo
```

Backend-specific state, operator, annihilation, and numerical-tolerance handling
must remain isolated from Decision Model's generic public contract.

## Required behavior

1. Consume the public API created in 017.01.
2. Translate successful transport results into explicit backend results without
   discarding cost, strain, residual, or provenance.
3. Preserve exact and near-annihilation as typed outcomes rather than fabricated
   probabilities.
4. Report backend identity and version in reproducible output.
5. Test all committed event fixtures relevant to the demonstration.
6. Verify that installation resolves compatible package versions.

## Documentation fence

State exactly which layer is being exercised:

```text
topographo:    certified OT transport mathematics
decision_model: computational resolver interface and presentation
```

Marketing may say that Decision Model can be backed by an executable OT
identity. It may not say that the integration proves general quantum
measurement, collapse, arbitrary POVMs, or universal intelligent evaluation.

## Done when

- the backend uses only supported `topographo` APIs;
- generic Decision Model code has no SSD-specific assumptions;
- annihilation and numerical tolerances are visible and tested;
- the demonstration identifies its backend and reproduces deterministically;
- scientific claims remain no stronger than the underlying certified result.
