## Result

**Decision Model** now exists under `packages/decision-model` as an independently
buildable, backend-neutral Python distribution.

The public computational contract is:

```text
ResolveEffect : State x Effect -> Probability
ResolveTest   : State x Test   -> Distribution
```

The stable `decision_model` import surface contains:

```text
State
Effect
Test
Probability
Distribution
Resolver
resolve_effect
resolve_test
ResolutionError
BackendResolutionError
InvalidResolutionError
AnnihilationError
```

`Probability`, `Test`, and `Distribution` are immutable validated values.
Effects are runtime-checkable callables. Tests are nonempty, ordered, uniquely
labeled effect families. Distributions are nonempty, ordered, uniquely labeled,
and normalized within an explicit tolerance; they never silently renormalize.
Resolution failure and annihilation remain distinct from successful probability
zero.

## Publication decisions

1. **Product and distribution name:** Decision Model / `decision-model`.
2. **Import name:** `decision_model`.
3. **License and owner:** MIT; The Swan Factory.
4. **Python support:** Python 3.11 and later.
5. **Backend dependency:** no runtime dependency in 1.0.0. A future topographo
   adapter may depend on public `topographo` APIs in one direction.
6. **Stability:** symbols in `decision_model.__all__`, their call shapes,
   endpoint invariants, strict normalization, and typed failure boundary are
   stable for 1.x.
7. **Placement:** `packages/decision-model` is a transitional monorepo location
   with its own `pyproject.toml`, README, license, source tree, tests, lockfile,
   build artifact, and OIDC publication workflow.

The PyPI name was claimed on 2026-09-21 through the repository's trusted
publisher as version 0.0.1. That immutable reservation exposes no stable API.
The implemented contract begins at 1.0.0.

## Dependency fence

The only permitted future dependency direction is:

```text
decision_model.backends.topographo  --->  topographo
```

Generic Decision Model modules use only the Python standard library. AST tests
prove that generic `decision_model` does not import `topographo` and that
`topographo` does not import `decision_model`.

## Excluded boundaries

Preparation and test interpretation remain outside resolver semantics:

```text
Prepare   : Datum -> State
Interpret : TypedQuestion / OutputType -> Effect / Test
```

The package does not expose sampling, argmax, thresholding, narration, policy,
decision, action, Event enactment, state-driven effect generation, or language
encoding as resolver operations.

## Validation

Package-local lint, strict mypy, and 68 contract tests pass. CI executes the
typing and behavior contracts on Python 3.11, 3.12, and 3.13. The wheel and
source distribution build as `decision-model` 1.0.0, include the typed
`decision_model` namespace and license, contain no `topographo` files, and
declare no runtime dependency.

## Claim fence

Decision Model 1.0.0 certifies a software contract for typed resolution. It does
not claim a generalized physical measurement law, arbitrary POVMs, collapse,
conditioning, path interference, or intelligent evaluation. Backend-specific
mathematics must be implemented and justified by each backend.
