## A. Premise correction

### P2 — `Eff(E) = [0, 1_E]` is certified, not declared

Theory 27 §1 states the formal effect interval directly, and §2 defines

```text
Test_formal(E) = { (e₁,…,eₙ) : 0 ≤ eᵢ ≤ 1_E, Σᵢ eᵢ = 1_E }.
```

Theory 41 independently restates `Eff(E) = {e ∈ E : 0 ≤ e ≤ 1_E}` and proves intrinsic finite common-test extendability inside it. So `017.21a`'s premise table was wrong to bank P2 as its own declaration. The consequence is favourable: the 017.21a result rests on **one** new principle, not three.

What remains correctly fenced is Theory 41's distinction between formal effecthood and physical Test Realization. 017.21a kept that fence and this turn keeps it.

### P3 — abstraction boundary, now earned

The mathematics was never new. Theory 27 §2 supplies both

```text
ℙ(V) → S(E)        and        S(E) × Eff(E) → [0,1].
```

What 017.21a added was a *decision about where the compiler's codomain sits*. Sections E and F below convert that decision from a declaration into a justified boundary: one-shot evaluation provably factors through `S(E)`, and `S(E)` is minimal. The only declarative residue is the identity convention that two ambient rays with the same induced state count as the same compiler output — and current TDM vocabulary neither requires nor forbids that (§E, level 3).

### P4 — new, but not what it looked like

P4 is **not** forced by the canonicality requirement 017.20 actually stated. That ladder asks for invariance under declared source equivalence and equivariance under source automorphisms. 017.21a itself proved the source group acts *trivially* on `E`, so source-side naturality imposes nothing on the target at all. P4 instead demands a **fixed point of the target automorphism group**, which is an additional and different requirement. It is stronger than the stated canonicality condition.

An honest equivalent formulation is available:

> **no unsupplied structure** — the compiled state must be definable from the selected central character alone, without choosing a frame in `Sym₂(ℝ)` that the Type Schema never supplied.

Section G shows the states with no such extra frame content are exactly the invariant ones, so this formulation and P4 select the same family. That is worth stating because it removes the appearance of an arbitrary symmetry axiom.

Is P4 unnecessary after passing to the operational quotient? **Partly.** It is unnecessary for public behavior — §D exhibits a continuum of realizations with identical behavior and no invariant state anywhere. It is necessary for canonical representative selection, and it earns more than 017.21a claimed (§D, forcing).

## B. Public semantics

For a fixed Type Schema `Σ`, one realization `R` induces, per declared operation `d` with finite answer set `A_d`:

```text
F_R,d : Input_Σ,d → Δ(A_d),
F_R,d(x)(a) = C_R(x)( T_R(a) ).
```

Several operations package as one typed family `F_R = (F_R,d)_d`. The audited `Σ` declares one operation, `IncidenceDecision`, with `|A_d| = 2` and `|Input_Σ| = 49`. The audit verifies `F_R` is total, exact-rational, and valued in `Δ(A_d)` for every realization it constructs.

What this object is:

```text
the Σ-semantics of one realization
    = the complete observable projection of an internal realization
      onto the declared typed boundary.
```

What it is **not**:

- not *the semantics of a TDM contract* — the contract is `Σ` itself, which constrains which families are admissible without singling one out;
- not *the identity of a TDM instance* — 017.10 makes identity `Type Schema + Training`, and distinct artifacts induce one `F` (§D);
- it **is** only one observable projection of a richer instance, which is exactly why behavioral equivalence must not be equated with artifact identity (§8 below).

Because the declared schema rule already fixes every answer, `F` here carries no predictive content. It is a conformance object.

## C. State equivalence

`E_Σ` is the family of formal effects some declared test actually evaluates. The notation is not invented here: top-level 15 §8 already writes `𝓔_Σ ⊆ Eff(E)` for a schema-induced effect family.

For the audited `Σ`:

```text
E_Σ = { z_M, z_s },        z_M + z_s = 1_E,
closure under coarse-graining = { 0, z_M, z_s, 1_E }.
```

`E_Σ` is **orientation-independent as a set** — the orientation bit permutes which answer label maps to which central effect, so it cannot affect the relation defined from `E_Σ`. Coarse-graining adds nothing: the audit verifies the closed family induces the same relation.

Define

```text
ω ≈_Σ ω′   ⟺   ω(e) = ω′(e) for every e ∈ E_Σ.
```

This is the kernel of `ω ↦ (ω(e))_{e ∈ E_Σ}`, hence automatically an equivalence relation; reflexivity, symmetry and transitivity are also checked mechanically on all 25 × 25 probe-state pairs. Unitality plus `z_M + z_s = 1_E` collapses two declared values to one:

```text
ω ≈_Σ ω′   ⟺   λ(ω) = λ(ω′),        λ = ω(z_M),   ω(z_s) = 1 − λ.
```

Verified as an exact biconditional on every probe pair. Therefore

```text
S(E) / ≈_Σ  ≅  [0,1].
```

Surjectivity is witnessed by `ω_λ` on a 13-point grid.

The relation is strictly coarser than equality. At `λ = 1/2` the audit exhibits three distinct states

```text
ρ = diag(1/2, 0),   ρ = diag(1/4, 1/4),   ρ = ¼·[[1,1],[1,1]]      (q = 1/2)
```

that are mutually `≈_Σ`-equivalent and each pair separated by an effect **outside** `E_Σ`. The fibers are two-real-dimensional for every `λ > 0`.

The degenerate case is exact and worth recording:

```text
λ = 0  ⟹  r₁₁ = r₂₂ = 0  ⟹  r₁₂² ≤ r₁₁r₂₂ = 0  ⟹  ω = δ_s.
```

So the `λ = 0` fiber is a single point. Confirmed by exhausting a rational state grid.

The three special cases the task asked for:

| Declared family | Quotient |
|---|---|
| `E_Σ = Eff(E)` | equality; separation forces `ω = ω′` (verified on all 295 distinct probe pairs) |
| one fixed finite test | many states observationally identical |
| the 017.21a central test | exactly `[0,1]`, via `λ` |

And the two compiled states are **not** `≈_Σ`-equivalent: `λ(τ_M) = 1`, `λ(δ_s) = 0`. The central test does separate the states. What it cannot separate is the two *labeled realizations*, which is a different question.

## D. Realization equivalence

A full realization is `R = (C, T)`: a compiler into `S(E)` and an interpretation of declared answers as effects with `Σ_a T(a) = 1_E`. Define

```text
R ≈ᵀᴰᴹ_Σ R′   ⟺   F_R = F_R′.
```

Again the kernel of a map, hence an equivalence relation; verified mechanically. The relation permits **coordinated** internal change, and the audit exercises that in two different ways.

**The two orientations.** Both change the compiled state *and* the answer-to-effect labeling:

```text
orientation 1:  incident ↦ τ_M,  incident ↦ z_M     ⟹  τ_M(z_M) = 1
orientation 2:  incident ↦ δ_s,  incident ↦ z_s     ⟹  δ_s(z_s) = 1
```

All 98 rows of `orientation_behavior_table.json` agree in every public column and differ in every internal state column.

**The rank-one rivals.** For any rank-one projection `P` the pair `(P, 1_E − P)` is a formal test, and `(ω_P, δ_s)` or `(ω_P, ω_{P⊥})` reproduces the declared behavior exactly. The audit instantiates 18 such realizations from exact Pythagorean directions. None uses a central effect; the second family uses no invariant state at all.

Result: **20 audited realizations, 20 distinct internal contents, 1 public family.** The class of the declared behavior contains at least an `ℝP¹` family.

That reframes 017.21a's headline. The orientation bit is not a distinguished two-element residue at the observational layer; it is the two-point slice that P4 plus centrality cuts out of a class with at least one real dimension.

### What P4 actually forces

This audit strengthens 017.21a. An invariant state sees only `(Tr A / 2, s)`, so with `t = Tr(A_e)/2 ∈ [0,1]` and `s = s_e ∈ [0,1]`,

```text
ω_λ(e) = λ·t + (1−λ)·s.
```

A convex combination equals `1` only if the active coordinate is `1`, and equals `0` only if it is `0`. Requiring both for one `e` forces `λ_I, λ_N ∈ {0,1}` with opposite choices; `t = 1` with `0 ≤ A ≤ I₂` forces `A = I₂`, and positivity of the complement then forces `s = 0`, giving `e = z_M`. The mirror branch gives `e = z_s`.

An exhaustive search over 225 grid effects — 200 of them non-central, 100 with nonzero off-diagonal — and all 169 `λ` pairs returns **exactly two** solutions, both with a central slot. So:

> **P4 plus the declared deterministic behavior forces the test to be the intrinsic central test.** 017.21a assumed centrality; it is derivable.

The last row is the one that matters. Every one of 11 target-automorphism probes fixes `z_M` and `z_s` pointwise, and the structural reason is exact: an automorphism permutes the minimal ideals, and those ideals have dimensions 3 and 1, so none can exchange them.

Therefore, from the task's list of allowed classifications:

```text
observable constitutive residue          rejected — behavior is identical
certified representation gauge           rejected — no symmetry relates them
unobservable internal ambiguity          accepted
```

with the exact definition:

> **Σ-unobservable labeled-realization ambiguity.** Two complete labeled realizations `R`, `R′` with `F_R = F_R′`, whose internal pair (compiled state, answer-to-effect labeling) differs, and such that no certified symmetry of the target datum carries one to the other.

It is an implementation choice. Calling it gauge would import a symmetry that demonstrably does not exist.

## E. Ambient rays

`q : ℙ(V) → S(E)`, `[x] ↦ ω̂_[x]`, is the certified Theory 27 map.

### Level 1 — formal OT preparation

The 017.21a same-copy control is reconfirmed: `u₀+v₀` does **not** induce `τ_M`, so the cross-copy convention remains load-bearing.

### Level 2 — formal TDM evaluation

No declared test can distinguish them, and the statement is a theorem rather than an observation:

> If `q([x]) = q([y])`, then for every formal test `T = {eᵢ}` with `eᵢ ∈ Eff(E)` and `Σᵢ eᵢ = 1_E`,
> `P(i | [x], T) = ω̂_[x](eᵢ) = ω̂_[y](eᵢ) = P(i | [y], T)`.

Proof: Theory 27 §2 factors evaluation as `ℙ(V) → S(E)` followed by `S(E) × Eff(E) → [0,1]`, so probabilities depend on `[x]` only through `q([x])`. The declared `IncidenceDecision` test is one such `T`. Checked mechanically on 20 probe effects for every exhibited fiber ray.

### Level 3 — TDM instance identity

Neither 017.10 nor top-level 15 requires preservation of which ambient ray realizes `ω` — and neither forbids it. 017.10 makes the Type Schema the public type boundary and says internals may differ radically. Top-level 15 §8 asks Training to constitute a state over `𝓔_Σ`, which is already a statement at the state layer.

So ambient-ray identity is **below the declared public boundary and simply undefined** by current TDM vocabulary. That is a terminology gap, not a derived identity rule, and it must not be inferred in either direction.

## F. State boundary

Taking the six questions in order:

1. **Does every one-shot evaluation factor through `S(E)`?** Yes, by certified Theory 27 §2.
2. **Are all probabilities for all formal effects preserved?** Yes; states are functionals on `E ⊇ Eff(E)`.
3. **What is forgotten from `[x]`?** Every component of the associated rank-one form orthogonal to the 4-dimensional image of `ι` — 132 directions of `Sym(V)`.
4. **Is any of it observable through the declared interface?** No, by the level-2 theorem.
5. **Would dynamics, Interact, physical preparation, or enlarged effect families need more?** Possibly, and this audit does not decide it. Theory 27 §§5, 7 leave the physical map to `[x]` open and warn that an enriched retained datum may refine the admissible equivalence class, which would require rechecking this boundary.
6. **So what is `S(E)`?** The **canonical and minimal** one-shot evaluator state.

Minimality is the part worth stating carefully. `Eff(E)` contains a linear basis of `E` — the audit exhibits `{z_s, z_M, E₁₁, G₊}`, all four effects, with exact nonzero determinant. Hence `ω ↦ (ω(e))_{e ∈ Eff(E)}` is injective, and any strictly coarser carrier loses a formal probability.

The honest answer is layered:

```text
[0,1]   via λ      sufficient for the declared Σ
S(E)                canonical and minimal for all formal one-shot evaluation
ℙ(V)                strictly redundant for one-shot evaluation, not for enactment
```

`Evaluate ≠ Enact` is preserved. A positive `S(E)` boundary for one-shot evaluation says nothing about autonomous dynamics.

## G. Invariant family

`Aut(E, E₊, 1_E) = O(2)/{±I}` acts by `(A,s) ↦ (QᵀAQ, s)`; the scalar ideal is fixed because the two ideals are non-isomorphic.

The audit stacks `(M_α − I)` over 11 probes — 10 exact rational rotations from Pythagorean triples plus the reflection — and computes the exact null space:

```text
rank 2,    kernel = span{ (1,0,1,0), (0,0,0,1) }
```

that is, `r₁₂ = 0` and `r₁₁ = r₂₂`, so `ρ = (λ/2)·I₂`. Unitality gives `q = 1 − λ`, and positivity bounds `λ ∈ [0,1]` — both `λ = −1/3` and `λ = 4/3` are verified to fail. Therefore

```text
ω_λ(A, s) = λ · Tr(A)/2 + (1 − λ) · s,        λ = ω_λ(z_M) ∈ [0,1],
```

**are exactly** the `Aut(E,E₊,1_E)`-invariant normalized states. The claim in 017.22 §7 is confirmed, not refuted. Sufficiency is checked on a 13-point grid; every non-invariant probe state is detected by at least one rational probe, so the probe set is not too weak.

Provenance split:

- from certified target algebra: the automorphism group, its action, the non-isomorphic ideals, `Eff(E) = [0,1_E]`;
- from the invariance requirement: `ρ` scalar, hence the one-parameter reduction;
- still a declaration: that invariance is the right requirement at all — i.e. P4.

One consequence deserves its own line, because it is what reclassifies P4:

> `λ ↦ ω_λ` is an exact bijection from `S(E)/≈_Σ` onto the invariant states.

Each observational class contains exactly one invariant state. P4 is a canonical **cross-section** of the observational quotient.
