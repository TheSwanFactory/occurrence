## Result

The established single-step OT Born transport identity is now a supported
package API:

```python
from topographo import (
    BornTransportAnnihilation,
    BornTransportResult,
    ot_born_transport,
)
```

`ot_born_transport(state, settlement_operator, complex_structure)` accepts a
real finite unit state of shape `(16,)` and real finite `K_a` and `J` matrices
of shape `(16, 16)`. Before transport it validates the algebraic relations that
force the identity: operator and complex-structure antisymmetry, `J^2 = -I`,
unit event recovery, and compatibility of transported spine axes with Hermitian
event axes. Arbitrary same-shaped matrices are rejected. A successful call
returns an immutable `BornTransportResult` exposing:

```text
transported_state               x' = K_a x / ||K_a x||
normalization_cost              ||K_a x||^2
event_strain                    cost - 1
post_transition_spine_share     s(x')
hermitian_numerator             A(z_a, x)
identity_residual               s(x') * cost - A
```

The returned state owns immutable storage. Inputs are not modified.

## Annihilation contract

Exact and numerical near-annihilation raise typed
`BornTransportAnnihilation` before normalization. The exception records:

```text
kind        "exact" or "near"
cost        squared norm ||K_a x||^2
threshold   configured squared-cost threshold
```

The default threshold is `1e-12`. Passing zero requests exact-only handling.
Malformed dimensions, complex or non-finite values, non-unit states, invalid
tolerances, and non-finite derived arithmetic are rejected explicitly.

## Scientific fence

This API is the **OT Born transport identity** or **single-step Born quotient**.
It establishes one retained-state transition. It does not establish a complete
generalized measurement law, tests or normalized outcome families, multistep
composition, path interference, conditioning, projection, collapse, density
matrices, or POVMs. It is distinct from
`topographo.ssd.fixed_head.readout_probability`.
