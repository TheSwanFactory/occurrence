## Objective

Promote the already-certified single-step OT Born transport identity from inline audit arithmetic into a reusable `topographo` API. Preserve the exact scope of Theorem 4.3: this is a transport identity for one retained state and one settlement operator, not a complete generalized measurement law.

## Required implementation

Add a narrowly named module under `topographo` that accepts:

```text
state x
settlement operator K_a
canonical complex structure J
```

and returns a typed immutable result exposing:

```text
transported state x' = K_a x / ||K_a x||
normalization cost ||K_a x||^2
event strain cost - 1
post-transition spine share s(x')
Hermitian numerator A(z_a, x)
identity residual s(x') * cost - A
```

The implementation must validate shapes and finite values and must define explicit behavior for exact and numerical near-annihilation. It must never divide by zero or rely on random sampling to avoid `ker(K_a)`.

## Integration

Refactor only `verify/occurrence_ii_audit.py` to call the package API. Keep `verify/occurrence_ii_codex_sol.py` and `verify/occurrence_ii_solomonjoseph.py` implementation-independent.

Add deterministic package tests covering:

1. all 84 committed events;
2. the chosen state-scale contract;
3. exact and near annihilation;
4. agreement with the existing canonical formula;
5. malformed dimensions and non-finite inputs.

## Naming and claim fence

Use **OT Born transport identity** or **single-step Born quotient** in the public API and documentation. If “generalized Born rule” appears, qualify it immediately as this established OT single-transition identity.

This step does not establish tests, normalized outcome families, multistep composition, path interference, conditioning, projection, collapse, density matrices, or POVMs.
