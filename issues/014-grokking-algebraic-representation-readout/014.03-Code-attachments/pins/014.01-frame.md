# 014.01 — Owner frame: grokking as readable algebraic representation emergence

- **Opened:** 2026-09-15T13:06:00Z
- **Originator:** gpt

## The idea worth preserving

The package has reached an unusual position for a grokking experiment: if a learner discovered the relevant algebraic organization, we may be able to **recognize it directly and invariantly**, rather than infer it only from a test-loss curve.

The central hypothesis is not simply that grokking improves generalization. It is that, on a suitable exact relational benchmark, grokking may correspond to a representational phase change:

```text
fit observed answers
        ->
form a task-aligned relational/algebraic organization
        ->
unseen answers become consequences of that organization
```

A concise phrase for the intended distinction is:

> **Grokking may be a transition from answer-sufficient representation to consequence-sufficient representation.**

That sentence is a conjectural frame, not a settled definition of grokking.

## Why we might be able to see it

For the structures already studied in this package, the latent target can often be stated without choosing coordinates. We know exact finite relations, quotient structure, incidence, automorphism groups, relabeling actions, and held-out consequence laws. Therefore a future hidden-state analysis can ask for an **isomorphism certificate up to natural symmetry**, rather than asking whether individual neurons match human labels.

The right standard is something like:

```text
hidden representation
    -> recovered quotient / relation
    -> exact certified algebraic object up to symmetry
    -> held-out consequences generated by that same object
```

If possible, the final arrow should be made causal: intervention on the recovered structure should selectively damage the corresponding consequence behavior.

## What would make this more than ordinary probing

The experiment should be designed so that the representation test is fixed before the grokking trajectory is inspected. Candidate observables can include quotient recoverability, exact incidence, automorphism covariance, role-completion structure, transport under relabeling, and consequence closure. The exact set should depend on the chosen benchmark rather than become a generic checklist.

The temporal ordering is part of the scientific question. If the certified algebra becomes readable before held-out accuracy jumps, that supports one mechanism. If generalization precedes algebraic readability, that argues against the simple story. If the algebra is merely decodable but ablation shows it is dispensable, then it is not yet the mechanistic explanation.

## Candidate substrates

009 and 011 are obvious sources of certified finite target structure, but the future experiment should choose the smallest benchmark that cleanly separates memorization from structural generalization and permits dense training checkpoints. It should not simply rerun those issues and rename successful generalization “grokking.”

007's `H_weak / H_rel / H_native` separation remains useful: the first grokking-readout experiment may only need to test whether one learned relational representation supports unseen consequences. It need not solve the stronger native-result-interface question in the same experiment.
