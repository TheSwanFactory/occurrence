## Scientific question

Can an overparameterized learner on a finite OT-derived relation first **memorize designated answers** and only later reorganize its internal token representation so that other admissible answers become consequences of the same learned relation?

The intended distinction is:

```text
answer-sufficient representation
    enough structure to fit the designated training answers

consequence-sufficient representation
    enough relational structure that alternate result roles, and possibly
    wholly unseen relation blocks, are generated by the same organization
```

Do not assume a grokking transition will occur. A clean absence is a valid result.

### 1. Freeze a memorization-versus-consequence benchmark

#### 1.1 Whole-block holdout

Enumerate the 56 unordered blocks in lexicographic order of their canonical Event-index triples. By deterministic backtracking, choose the **lexicographically first set of eight blocks** satisfying both:

1. the eight held-out blocks are pairwise Event-disjoint; and
2. after removing them, the incidence graph of the remaining 48 training blocks and all 84 Events is connected after isolated vertices, if any, are rejected.

Every Event appearing in a held-out block must appear in at least one remaining training block. Given the certified degree structure this should follow from pairwise disjointness, but verify it directly.

If no such eight-block set exists, report `BLOCKED` rather than changing the number eight after seeing model behavior.

Call these eight blocks `NOVEL_BLOCK`; the other 48 are `SEEN_BLOCK`.

#### 1.2 One designated result role per seen block

For each canonical sorted triple `(x0,x1,x2)` in the 48 `SEEN_BLOCK` blocks, compute

```text
r = int(SHA256("014/role/v1|x0,x1,x2"), 16) mod 3
```

The designated training target is `x_r`; the other two Events are the unordered input pair. The main architecture below is exactly input-swap invariant, so store one unordered training example per block.

This produces:

```text

ROLE_TEST    96 alternate-role examples, two per seen block
```


### 9. Scientific interpretation

Keep these claims separate:

```text
A. MEMORIZATION
   main model fits the 48 designated TRAIN answers

B. ROLE CONSEQUENCE
   alternate output roles on seen triads become correct

C. GLOBAL EXTRAPOLATION
   wholly unseen block triples become correct

D. REPRESENTATION READABILITY
   a fresh shared decoder trained only on TRAIN can recover B/C from frozen token representations

E. LOAD-BEARING LOCATION
   component transplant localizes some or none of the behavioral transition to token representation
```

A positive result may support, at most, a finite mechanistic statement that a learned opaque-token representation became relation-readable around a delayed consequence-generalization transition.

It does **not** establish:

```text
all grokking is algebra discovery
low dimensionality is necessary
our SFP coordinates appeared neuron-by-neuron
OT is superior to transformers or language models
H_native / Outcome constitution
open-ended or language-scale representation discovery
physical Event or Outcome semantics
that probe decodability by itself proves causal use
that NOVEL_TEST success is guaranteed by the training examples
```

If ROLE_TEST groks but NOVEL_TEST does not, say exactly that: the learner acquired role-neutral triad consequence without evidence of the stronger unseen-block algebra.

If the representation probe becomes readable before behavior, that is especially informative; if behavior comes first, report it rather than forcing the intended story.
