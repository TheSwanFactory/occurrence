# 13 — Query-relative consequence addressing

## Executive result

On the frozen finite FIPS admit-and-force benchmark, **representation-aligned, query-relative consequence addressing materially improves held-out consequence generalization**, and the gain is not explained by merely giving the learner a larger pointer-style head.

Under the governing deterministic execution contract established in Issue 013, the relationally aligned SFP arm `B` gives:

```text
LOHO PP-set accuracy             0.973214
LOHO forced-third accuracy       0.964286
```

against the frozen absolute-address predecessor:

```text
LOHO PP-set accuracy             0.715774
LOHO forced-third accuracy       0.701637
```

for gains of `+0.257414` and `+0.262686`, with paired 95% intervals `[+0.212798,+0.300595]` and `[+0.215774,+0.308036]`; all fourteen LOHO folds favor the query-relative system.

The matched-capacity non-automorphic scramble control `C` receives the same pointer architecture and parameter count but does not receive the relational benefit. In the deterministic run, the Rung-2 LOHO forced-third `B-C` effect is `+0.789435`, interval `[+0.758929,+0.816964]`, and every reported `B-C` interval is positive. This is the load-bearing capacity control.

The core effect has an **independently reproduced semantic match** in `012.04`. Issue 013 then froze a deterministic runtime contract before scored replay and obtained two complete normalized sweeps that are byte-identical, with byte-identical frozen analyses. Both deterministic analyses satisfy the frozen `B≈D` rule and give class **A**.

The strongest current conclusion is therefore finite and representation-level:

> **For this exact finite relation, consequence generalization depends strongly on whether the learner's result-addressing representation is aligned with the certified relational structure. A query-relative pointer exposes that structure to the learner; the same architecture applied to a marginal-matched non-automorphic scramble does not.**

This is not a claim of generic learning superiority, language-scale generalization, or SFP discovery.

## Scope and objects

The experiment uses the fixed `009` finite substrate, splits, seeds, relation, candidate construction, fixed resolver, and structural controls. The principal arms are:

```text
B  certified SFP relational code with query-relative candidate pointer
C  marginal-matched, non-automorphic scrambled code with the same pointer architecture
D  certified structure-preserving relabeling
A  native-coordinate comparison arm from the frozen experiment
```

The query-relative head is structurally a pointer network: one shared scorer ranks a supplied candidate set rather than learning an output column for each absolute chamber identity. Pointer-network architecture itself is prior art (Vinyals, Fortunato and Jaitly, 2015). The package-specific evidentiary contribution is not invention of the pointer mechanism; it is the **matched relational-misalignment control** and exact finite structural audit showing that the same pointer capacity helps the aligned code and not the scramble.

Across turns, the pointer pathway has 894 more parameters than the old absolute PP head, so the raw `009.06 -> 009.08` improvement is not capacity-matched by ledger alone. The within-turn `B` versus `C` comparison is what supports the alignment claim.

## What changed from the historical disposition

The producer `009.08` execution filed class B because three of sixteen `D-B` intervals excluded zero; the narrowest relevant exclusion cleared zero by only `0.000744`. The independent fresh replay in `012.04` moved `D` enough that zero of sixteen intervals excluded zero and therefore filed A.

Issue 013 did not choose the favorable replay after seeing it. It froze deterministic execution controls first, then ran two complete 672-cell sweeps from clean processes. The two normalized scientific outputs and analyses are byte-identical, with `0/16` `D-B` intervals excluding zero. The Owner therefore adopts **A under that governing deterministic contract**.

The historical B result is not erased or relabeled. The audit establishes a stable successor execution contract; it does **not** establish which specific nondeterminism surface caused the earlier drift.

## Interpretation

The stable progression remains:

```text
opaque 84-way output identity       -> weak held-out consequence
absolute structured PP address      -> much stronger consequence
query-relative relational address   -> near-ceiling consequence
```

The scientifically useful reading is that **output constitution is load-bearing** on this finite benchmark. A representation can carry the relevant relation while an ill-matched result object makes that relation difficult to use for held-out consequence.

This does not show that the learner discovered SFP. In `009.08`, the relational code and candidate stars are supplied. Local representation discovery is a separate result in `009.10`; global finite quotient discovery is a separate result in `011`.
