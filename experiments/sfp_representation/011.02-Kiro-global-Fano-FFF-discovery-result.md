### The automorphism group of the observed graph, derived not guessed

```text
|Aut(observed anonymous graph)| = 43008 = 168 x 128 x 2

  5040   L-images enumerated exhaustively
   168   extend to a graph automorphism at all          (stage 1)
   128   automorphisms per surviving L-image            (stage 2, the 2^7 sign choices)
     2   the L/R namespace swap coset

```

The closure argument is recorded with the census: the degree spectrum separates `H`
(6) and `E` (3) from `L` and `R` (12), so any automorphism preserves `{H}`, `{E}`
and `{L, R}`; an automorphism fixing `L` and `R` setwise is determined by its
L-image, which forces the class map and hence the R-image, plus one sign bit per
class, which forces the habitat map and hence the Event map because
`(habitat, left)` is a key on Events. The `168` is *not* imported from `gl_3_2`; it
falls out of the enumeration and is then compared to it.

indistinguishable from the observation and no learner could be blamed for missing

## 5. Architecture and the anti-identity ledger

```text
h <- LayerNorm(h + ReLU(Update([h, pooled])))          4 rounds
m_ij = Message(h_j)                                    PRIMARY
pooled = sum over incident neighbours
width 32 everywhere, carried from the frozen 009.02 ScorerConfig constants
two readout heads over one shared encoder, one per query kind
19394 parameters (primary)   23490 (repair)
```

Four rounds is the Gate-0 path length, declared before the probes: habitat mark →
Event → axis node, which can form "exactly one query-marked habitat" → Event, which
conjoins its left-side and right-side signals → habitat. Mate needs the same four
hops, `h -> E -> L -> E -> h'`, to compare a mate's six shared axis nodes against a
non-mate's five.

### Anti-identity audit

```text
embedding modules                                    0
buffers                                              0
parameter dimensions equal to 7, 14, 84, 112 or 266  0
learned output columns indexed by a habitat          0
learned output columns indexed by an Event           0
learned output columns indexed by an axis            0

parameter count at 11 / 40 / 112 / 266 / 300 nodes   19394 at every one

```

`FanoConfig` **refuses** a width equal to any typed node count, so the audit cannot
be blunted by a coincidence. The head index is an episode-level choice, not a node
feature, so it cannot carry identity either.

### Invariances

```text
completion query swap invariance          84 of 84 input tensors bitwise identical
                                          84 of 84 score tensors bitwise identical
fresh-name score transport                worst discrepancy 2.5e-07  (tolerance 1e-05)
fresh-name decision transport, decisive   168 of 168 exact         (perturbed probe)
global L/R namespace swap                 1.0000 identical decisions, all 32 runs
```

Swap invariance is bitwise because the query is written as a **set** mark: the
tensors for `(h1, h2)` and `(h2, h1)` are the same object, so invariance is a
property of the encoding rather than something the optimizer has to find.

Decision covariance needed care and gets it. At initialization this architecture is
degenerate — `LayerNorm` plus a mark on one node in 112 leaves every habitat score
equal to about `1e-7`, so **every** row is tied and an all-rows decision rate would
measure the index tie-break rather than the model. The audit therefore separates
decisive rows from tied rows and runs a second pass on a deterministically perturbed
model, which is never trained and from which no accuracy is read. On its 168
decisive rows the decision transports exactly.

### No answer rule on the learned path

An AST walk over `fano_heads`, with annotations, docstrings **and the ban list's own
string literals** excised, finds:

```text
banned identifiers in code    0 of 24
bitwise-XOR operators in code 0
```

The excision matters in both directions. Prose that names a banned symbol — this
file's own documentation names several — cannot trip the check, and
`BANNED_IDENTIFIERS`, which is a tuple of exactly the strings being searched for,
cannot satisfy it. String constants *are* searched, so `getattr` by name is covered.
The banned set includes every `hidden_*` field, `certified_mate`,
`certified_completion`, `reconstruct`, `plane_audit`, `line_preserving_bijections`,
`automorphism_census`, `LINES3`, `POINTS3`, `gl_3_2`, `third_point`, `SfpCodec`,
`ExactSfpCircuit` and `fips_basic`.

XOR appears in this turn exactly twice, both outside the learner:
`Observation.certified_completion` generating targets, and
`hidden_label_agreement` auditing the recovered lines.

### The sparse edge path is an optimization, not a second model

The repair block's dense implementation materializes a `(B, 112, 112, 64)` tensor
and masks it, wasting 96% of its work on absent edges — 252 undirected edges in
12544 cells. The sparse implementation gathers at the edge list and sums with
`index_add`. They agree to `4.8e-07`, and a batch carrying different graphs is
detected and falls back to dense rather than silently reading the first row.

### The sparse path was not replayable, and that is why determinism is switched on

This was caught by replaying the sweep rather than by reasoning, and it is reported
because it changed a published number.

The gradient of a gather is a scatter-add, and under CPU multithreading that
accumulates in a nondeterministic order. Two runs of the same seed at the same
commit diverged at step 59 — `2.5250608921` against `2.5248198509` — and the
divergence propagated: the repair block's reported completion rate moved from
`0.4235` to `0.5307` between runs. The primary block, whose reduction is a
`matmul`, was bit-identical across the same pair of runs, which is why the
primary numbers in this document are the same as in the first sweep.

`fano_heads` therefore sets `torch.use_deterministic_algorithms(True)` where the
model is defined, rather than leaving it to each caller. Both paths become
order-stable at roughly a 40% cost on the primary block and 25% on the repair, and
the sweep artifact replays to an identical runs digest. The repair block's numbers
in this document are from the deterministic run; the two earlier
nondeterministic values are quoted here so the defect is on the record rather than
quietly overwritten. Neither of them changes the finding — the repair does not
rescue the plateau in any of the three runs.

Three mechanisms, each checked rather than asserted.

**Two heads, because one cannot serve both queries.** A single shared readout reaches
`1.0000` on the mate query and **exactly `0.0000`** on completion — systematically
wrong rather than at chance, the signature of one readout pulled between two
functions of the same encoding. `011.01` section 4 describes "a graph encoder
followed by shared pointer/readout **heads**", plural, and two is what this needs.

**A residual path, because the counting channel is what the answer is made of.** An
exact propagation probe run with identity messages separates the mate by a clean
`12` against `10` in unnormalized neighbour counts, and separates the completion
target at `0` against `2`. Plain `relu(Linear([h, pooled]))` discards that channel
over four rounds.

**`LayerNorm`, because the informative difference is one unit in twelve.** An axis
node distinguishes "in the query's support" from "not" by one marked Event among
twelve neighbours; without per-node renormalization the type-driven baseline
dominates that margin.

The frozen configuration reaches training loss `0.346574`, which is the exact
information-theoretic minimum of this loss — `0` on a one-element mate target and
`ln 2` on a two-element completion target, averaged over two heads. The fit is not
merely good, it is complete. Six rounds also reaches it; four was kept because it
was declared first as the Gate-0 path length.

Same architecture, same `19394` parameters, same optimizer, same steps, same seeds.
The only difference is that L/R identity is localized inside each habitat. The arm

reconstructs a plane.

The tolerance is not zero for a stated reason. A ceiling like `1/13` is the
*expected* rate under uniform renaming; the frozen draw is finite, so a selector
exactly at its ceiling still lands `O(1/28)` away. Worse, a degenerate tie-break's
hits arrive in per-namespace blocks — on the completion query one namespace
contributes either 0 or 12 hits — so the effective sample size is the namespace
count, not the query count. The decision rule is the absolute comparison; the exact
binomial tail is reported alongside with that dependence stated rather than hidden.

## 9. Representation-recovery audit

Section 5 asks for more than query accuracy. On each test namespace the trained
model is queried exhaustively: all 14 mate queries, then — using one representative
habitat per predicted point class — all 21 class-pair completions.

```text
mate predictions form seven disjoint mutual pairs        0.8750
predicted completions close into seven three-point lines 0.7344
every point on three lines, every pair on exactly one    same rate
isomorphic to the certified Fano plane under exact 7! search   same rate
```

On the five converged seeds all three rates are `1.0000`; on the three stalled seeds
the mate pairing is not even mutual, so no plane is attempted.

**The entailment is stated, not implied.** `fano_plane_valid` and
`certified_plane_equivalent` are **not independent evidence**. A three-point-line
system on seven points in which every point lies on three lines and every pair lies
on exactly one line *is* the Fano plane — it is the unique `2-(7,3,1)` design. So
validity entails equivalence, the two rates agree by construction, and
`fano_sweep.summarize` asserts that they agree rather than reporting two findings.
No canonical numeric `FFF` label is produced or required; the plane is judged up to
`GL(3,2)`.
