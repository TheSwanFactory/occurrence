## 0. Fence

Strict `Occ` / `Cyc` / `Sand` on the exact rational path at `r = e4`. Denotations
recovered from training-side observations only and frozen before any held-out
evaluation. Exact projective native endpoint scoring throughout. No learned result

## 1. Answer

Two answers, and the second is the one that carries information.

**The commissioned question.** Does the `008.05` advantage survive train-only
recovered denotations? **Yes** — and trivially, because recovery is exact.

```text
                        motif          motif_parity
catalogue recovered     16/16          16/16
tied tokens             0              0
minimum vote margin     9105           8520
recovery penalty        +0.0000        +0.0000   (on every one of 8 seeds)
```

The recovered map equals the true map, so the recovered pool is bit-identical to
the true pool and `Delta_s = 0` is an **identity, not a measurement**. The
commissioned number exists, passes, and says nothing about robustness to
imperfect recovery.

**The question that had to be added.** Where does recovery actually have to fail
before the learned advantage dies? Fitting the same voting recovery to nested
subsamples of the same training half produces genuinely imperfect maps at no extra
cost, and running the frozen policy against them gives the curve:

```text
catalogue  obs   test    delta    reachable ceiling  test/ceiling  beats bar
  3/16      15   0.0067  -0.6603  0.0312             0.21          no
  7/16      88   0.1052  -0.5617  0.1683             0.63          no
 14/16     292   0.5042  -0.1628  0.7762             0.65          YES
 16/16     876   0.6670  +0.0000  1.0000             0.67          YES
 16/16    2921   0.6670  +0.0000  1.0000             0.67          YES
```

The advantage survives at 14/16 recovery and is gone by 7/16. The bar is 0.1495.

And the shape of the penalty is more informative than its size: **`test/ceiling`
is nearly constant at 0.63–0.67** wherever the sign bits survive recovery. The
recovery penalty is almost entirely a *ceiling* effect — imperfect denotations
shrink the set of inputs on which any program can reach the true endpoint, and the
policy goes on converting roughly the same two-thirds of whatever is left. Policy
learning is not what degrades. That is a cleaner attribution than section 11's
menu allows, and it is only visible because the degraded arms were run.

## 2. The interface change, stated plainly

`008.05` fed the policy the exact Event rays. There was nothing to recover: the
denotations *were* the input. Ladder D therefore cannot be run on the `008.05`
task as literally frozen, because "recovered denotation" is not well-typed unless
denotations are hidden behind something.

The minimal change is a token layer:

```text
008.05   exposed input = three certified Event rays          denotations given
008.07   exposed input = three TOKENS over a fixed vocabulary denotations hidden
```

A frozen sign-balanced vocabulary of 16 tokens over the 84 certified Events,
selected by a recorded seed, 8 with sign bit 1 and 8 with sign bit 0 so all eight
sign patterns stay equinumerous. Exhaustive over `16^3 = 4096` token triples,
3913 with a defined target.

Everything `008.06` section 7 pins is unchanged: `E^3 R`, the strict
`Occ + Cyc + Sand` calculus, `r = e4`, the twenty planar programs, the `008.02`
sign-bit target, the `StructuralPolicy` with its fixed `phi`, the `motif` and
`motif_parity` splits, the full baseline set, exact native scoring, and the
absence of a result decoder. `FlatPolicy` was not reopened.

Unlike `017`, the vocabulary is **not** the densest FIPS subgraph. The `008.02`
target lives entirely on the `Cyc`-free bracketings, so maximizing `Cyc` density
would only inflate the legal-program count with distractors and move the
availability structure away from `008.05`. A sign-balanced uniform sample is the
neutral choice.

This is reported as an interface change rather than presented as if the task were
untouched.

## 3. The three `008.06` gates

**Gate 1 — target independence.** The `008.02` sign-bit grammar, unchanged. Not
an availability rule, does not inspect model scores, no decoder.
`test_target_is_not_an_availability_rule` checks the availability part
mechanically: inputs sharing one availability pattern demand different programs.

**Gate 2 — program-space viability.** On the token task:

```text
availability ceiling   0.2083
learned headroom       0.7917
joint domain share     0.9912
endpoint disagreement  1.0000
legal programs         20
```

The ceiling is above the 84-Event value of 0.1489 because the per-pattern argmax
overfits harder on 3913 records than on 38137. That is the same upward bias
`008.05` section 2 documented, and it is conservative: it raises the bar.

**Gate 3 — target-signature holdout.** The gate the Owner installed in response
to `008.05` section 8.2, and it does its job:

```text
motif          withholds whole signature values   lookup 0.0786   discriminative
motif_parity   withholds whole signature values   lookup 0.0020   discriminative
random         does not                            lookup 1.0000   CONTROL
```

`random` is carried only as a cheap regression control and is explicitly
non-dispositive. `unseen_events` is **not** carried: under the token layer the
exposed input is a token, so withholding Event identities would withhold
vocabulary entries, which is a different experiment. `build_splits` now takes an
explicit split selection rather than silently producing an ill-typed cell.

## 4. Recovery

The banked Outcome-017 `Rec_ray` path — endpoint-inverse voting — transferred, but
not in its materialized form. At `E^2 R` with two programs the inverse map has
14112 entries; at `E^3 R` with twenty it has 11854080, which does not fit in
memory as a dict of exact ray keys. So the transfer is **streamed**: identical
arithmetic, identical votes, constant memory beyond the observed-endpoint index.
About seven CPU-minutes per split.

Training-side observation is `(token triple, exact native target endpoint)` and
nothing else — not the true denotations, not which program the hidden grammar
selected. Recovery is deliberately **grammar-agnostic**: it votes over all twenty
programs rather than the eight `Cyc`-free bracketings the grammar can reach, even
though that pool is public, because restricting to it would hand recovery a piece
of the relation the policy is supposed to learn.

One recovery per split. A map fitted on `motif`'s training half would leak into
`motif_parity`'s held-out half, since the two splits partition the same 4096
triples differently.

```text
split          train records   distinct endpoints   catalogue   ties   min margin
motif          2921            1626                 16/16       0      9105
motif_parity   1944            1104                 16/16       0      8520
```

### Leak audit

Mechanical, not asserted in prose. `audit_recovery_leak` rebuilds the observation
index independently and refuses recovery unless every check passes: the observed
triples are a subset of the training half, no held-out triple was observed, the
observed endpoint keys are a subset of the training endpoint keys, no
held-out-only endpoint appears in the index, and the recovery's own observation
count matches the audit's. `leak_free = True` on both splits, and the driver exits
non-zero without scoring if it is ever false. `test_leak_audit_catches_a_recovery_fitted_on_the_wrong_half`
verifies the audit can actually fail.

### Tie convention

`017.23`'s consistent first max — leftmost index attaining the maximum. Zero ties
arose at full observation, so no token's identity depended on catalogue order.
That is worth stating precisely because it is *not* true at low observation: at 15
observations, 4 of 16 tokens are tied and their recovered identity is decided by
catalogue order alone. Identifiability is a function of how much has been
observed, not a fixed property of the method.

### How much observation exact recovery needs

An added diagnostic, sharing one streamed pass, because "recovery was perfect"
without a scale is not a measurement:

```text
obs      6   15    29    88   292   876   2921
endpts   6   15    29    85   244   636   1626
16/16    -    -     -     -     -    yes   yes
match  4/16 3/16  3/16  7/16 14/16  16/16 16/16
ties     7    4     1     0     0     0     0
margin   0    0     1    45    34    661   9105
```

Exact recovery is reached by 876 observations and the full training half carries
roughly a **ten-fold margin** beyond what is needed. That is the reason the
commissioned robustness test cannot fail here, quantified.

## 5. Recovery diagnostics, by the four `008.07` section 6 modes

At full observation, all four are clean, which is the whole problem:

```text
representation recovery   16/16 catalogue, 16/16 sign bit, 0 ties, 0 order-sensitive
program-domain change     legal set changed on 0.0000 of inputs
endpoint change           target endpoint changed on 0.0000 of inputs
policy-selection failure  the only remaining mode; identical to the true arm
```

Under degraded recovery the modes separate properly, which is what makes them
worth having:

```text
catalogue  sign bits  legal set changed  target endpoint changed  test/ceiling
  3/16      9/16      0.2087             0.8835                  0.21
  7/16     13/16      0.1216             0.7803                  0.63
 14/16     16/16      0.0393             0.2383                  0.65
 16/16     16/16      0.0000             0.0000                  0.67
```

The sign-bit column is the interesting one. Once all 16 sign bits survive — at
14/16 catalogue accuracy — policy efficiency is already at its ceiling-relative
maximum. Below that, efficiency collapses to 0.21–0.30. The sign bit *is* the
target-determining signature, so corrupting it damages the policy directly rather
than only shrinking the reachable set.

### The `008.06` section 6 seed instability, now characterized

The Owner asked for enough seeds to keep ordinary Ladder-A variance from being
mistaken for recovery damage. At eight seeds the `motif` spread is real and wide:
**0.383 to 0.875**, sd 0.172, median 0.749. It is not an artifact of the three
seeds in `008.05` (0.966 / 0.322 / 0.991) — that sample happened to be bimodal
and its 0.7595 mean was optimistic relative to the eight-seed 0.6670.

`motif_parity` remains at 0.9943 with sd 0.0061 across all eight seeds. The
`008.05` observation that the harder-looking parity split is the *stabler* one
therefore replicates, and remains unexplained. Per `008.06` section 6 it was not
investigated.

Because the recovered and true arms are bit-identical, this variance cancels
exactly in `Delta_s` — the one benefit of the degeneracy.

## 8. Stop-rule accounting

`008.07` section 8 allows one recovered-denotation pass plus at most one repair
specific to the denotation/recovery interface.

```text
recovered-denotation passes    1
repairs                        0
FlatPolicy reopened            no
target / splits altered        no
free result decoder added      no
program-specific output column no
```

No repair was needed: the recovered rays are the same exact 16-coordinate
rational vectors the policy already consumed, so there was no numerical or typing
mismatch to fix.

Two things were **added** beyond the commissioned arms, both declared:

1. the **observation sweep** (section 4), a diagnostic on the recovery interface
   that shares one streamed pass and changes nothing about either arm;
2. the **degraded-recovery probe** (section 1), which runs the frozen policy
   against the sweep's imperfect maps.

Neither is a repair and neither touches the task, the target, the splits or the
policy. They exist because the commissioned measurement is vacuous, and reporting
`+0.0000` as if it were evidence of robustness would have overstated the result.
The driver detects this condition itself and sets
`degenerate_as_a_robustness_test = true` rather than relying on prose.

## 9. Reported problems — for Owner disposition

### 9.1 `008.07` sections 5/9/10 commission a measurement that cannot fail here

The recovery penalty is central to `008.06` section 8's interpretation rule, but
at this cell it is identically zero by construction. Endpoint-inverse voting over
`E^3 R` recovers all 16 tokens from 876 of 2921 available observations, with a
minimum vote margin of 9105 at full observation.

The cause is structural, not an implementation accident. Three Event slots and
twenty programs mean each observed exact endpoint constrains all three tokens
jointly, and exact rational arithmetic makes endpoints nearly unique — 1626
distinct endpoints over 2921 training triples. The `E^3 R` recovery interface
carries far more information than the `E^2 R` interface where `017` found recovery
hard. Ladder D got *easier* as the composition task got richer.

Owner decision needed: whether the Ladder-D specification gains a **recovery
difficulty gate** — a requirement that the recovery interface be shown capable of
failing before a survival claim is credited, analogous to Gate 2 requiring the
program space be shown capable of defeating availability. Without it, "the
advantage survives recovery" can be reported from a setting where recovery was
never in doubt.

The added probe in section 1 is what such a gate would look like operationally:
report the recovery-quality curve, and locate the learned advantage's breakdown
point on it, rather than reporting a single penalty at full observation.

### 9.2 The eight-seed `motif` mean is materially below the banked three-seed mean

`008.06` section 1 banks `0.7595` as the primary `008.05` held-out result. At
eight seeds on the token task the same cell gives **0.6670**, sd 0.172, and the
`008.05` three-seed sample was bimodal (0.966 / 0.322 / 0.991).

The two numbers are not directly comparable — 84-Event inputs versus a 16-token
vocabulary — so this is not a contradiction of `008.05`. But the direction is
consistent with the three-seed mean having been optimistic, and the qualitative
claim is unaffected: 0.6670 against a 0.1495 bar is a +0.5175 margin, material on
every seed.

Owner decision needed: whether the banked `008.05` headline is annotated with the
eight-seed figure, and whether future Issue-008 cells require a minimum seed count
rather than three.

## 10. Disposition

**Ladder D is positive**, on both discriminative splits, under the `008.07`
section 10 criterion:

```text
motif          recovered 0.6670  bar 0.1495 (RandomLegalTree)  margin +0.5175  8/8 seeds
motif_parity   recovered 0.9943  bar 0.1496 (RandomLegalTree)  margin +0.8446  8/8 seeds
recovery map   16/16, 0 ties, fitted train-only, leak audit clean
```

Qualified in one respect that the disposition should carry: the survival claim is
established against *exact* recovery, and the added probe shows it also holds at
14/16 recovery and fails by 7/16. So the honest earned claim is

```text
At E^3 R with strict Occ+Cyc+Sand, learned compositional advantage over every
deployable deterministic baseline survives a nonleaky train-only denotation
recovery boundary, and continues to survive down to 14 of 16 tokens correctly
recovered, breaking somewhere between 14/16 and 7/16.
```

**Failure classification:** not applicable to the primary result. For the
degraded arms the dominant boundary is **denotation recovery quality** operating
through the reachable ceiling, not policy optimization: `test/ceiling` holds at
0.63–0.67 across 7/16, 14/16 and 16/16 recovery.

### Issue 008 closure

**Ready to close on the composition question.** `008.02` established that the
strict program space contains lawful choice, `008.05` that a structural policy
exploits it beyond every deployable deterministic baseline, and this turn that the
advantage does not depend on denotations being supplied.

One narrower follow-on is warranted, and it should **degrade the recovery
interface** rather than run another ladder: fewer observations, partial or noisy
endpoint reporting, or a vocabulary large enough that voting is genuinely
ambiguous. The instrument for it already exists in
`recovery.recover_observation_sweep` and `probe_degraded_recovery.py`. The
alternative — accepting Ladder D as closing the recovery question — would rest on
a test that could not have failed.
