## 2. Task and split construction

Identical native-structure task to 017.11/017.12: fixed hidden `ε*` on densest FIPS 16-subset; preferred legal tree targets; ~35% pair-combination holdout; `r=e4`; seeds 0–2. Per-seed sizes train 149/143/152, test 75/81/72. Oracle exact train/test **1.0** on all seeds.

Single-phase baselines (A_joint / B / C) use **800** steps (matched to 017.12). Curriculum arms use **1600** wall steps by design.

## 3. Strict native predicates

```text
Occ(e,r) = [e*r] if e*r ≠ 0 else undefined
Cyc(a,b) = [a*b] if (finite FIPS proxy) else undefined
P_seq(a,b,r) = Occ(a, Occ(b,r))
P_grp(a,b,r) = Occ(Cyc(a,b), r)   # masked unless Cyc-admissible
```

Native comparison: sign-insensitive projective ray equality.

**Relaxation (train only):** Gumbel-Softmax STE over catalogue; soft Cyc score gates the soft program mixture in phase 2. Eval uses hard argmax denotations + hard proxy.

## 9. Failure analysis

**Verdict: partial positive — curriculum raises discrete A well above ~0.035; freezing ε in phase 2 is the stronger stabilizer; joint phase 2 re-dilutes geometry.**

1. **Material lift vs A_joint.** A_cur test exact **0.186 ± 0.026** (~5× A_joint ~0.035). A_cur_freeze **0.409 ± 0.031** (~12×), matching/slightly exceeding C (~0.37) while allowing a learned policy.
2. **Phase-1 works as designed.** Force-seq warm-start recovers the same catalogue/adm geometry as C (Jaccard ~0.69; ~53 edges; ~10/16 idx).
3. **Joint unlock harms geometry.** Continuing to train ε under the soft adm-gated mixture undoes much of the warm-start (Jaccard 0.69→0.32). This supports the 017.12 hypothesis that A's mixture dilutes seq-driven catalogue recovery — even *after* a good warm-start.
4. **Freeze ablation is the clear winner among curriculum variants.** Recovered geometry + learned π alone reaches ~0.41 held-out exact without needing further ε updates. Still well below B (~0.91) with true ε*.
5. **Baselines unchanged.** A_joint / B / C / Oracle match 017.12 — no codepath drift.
6. **Does not close the gap to B.** Policy under recovered-but-imperfect ε* still leaves ~0.5 absolute held-out deficit vs true geometry. Soft `mean_w_grp` during phase 2 is higher than hard grp choice, suggesting soft training still over-weights grp relative to hard-adm eval.

Does **not** claim Issue 017 closed; does **not** claim modular grokking.

## 10. Recommended next GPT step

1. **Keep ε frozen after warm-start as default** for discrete Futurator A; treat joint phase-2 ε updates as harmful under current soft adm gate.
2. **Improve policy exploitation of recovered adm:** A_cur_freeze still chooses grp only ~12% of test pairs despite ~53 hard edges / ~31 disagree edges present — diagnose policy under-use of grp (init, log-barrier scale, longer phase-2, or supervised branch CE on preferred trees).
3. **Optional:** supervised catalogue CE / ray-implied labels in phase 1 (vs force-seq proj loss only) to push idx match above ~10/16 toward B's 16/16.
4. Only after discrete-A approaches B-level held-out exact, attempt rigid external relation / modular stage (017.09 §4.2).
5. Owner may promote/close only after interpreting whether learned geometric admissibility + curriculum policy contributes under a working discrete head; this filing does **not** close Issue 017.
