## 0. Fence

Configured experiment on the **finite** basic-Event / FIPS-style Cyc proxy. Not physical OT enactment, not modular grokking, not continuous certified locus `C`. Soft surrogates are not success criteria. Issue 017 **not** closed by this experiment alone.

## 1. Motivation (from 017.12 §10.1)

Discrete catalogue head unlocked hard FIPS reachability, but primary arm A stayed near floor (exact test ~0.035; Jaccard ~0.06) while force-seq arm C recovered geometry (Jaccard ~0.69; exact ~0.37). Hypothesis: A's soft adm-gated mixture dilutes seq-driven catalogue recovery. Recommended next step: **curriculum / two-phase train** — warm-start ε under force-seq, then unlock π.

## 2. Phase protocol (primary curriculum arm)

**Budget choice (documented):** **800 + 800** of a 1600-step curriculum budget (N1 phase-1 force-seq ε, N2 phase-2 unlock π). Single-phase baselines remain at **800** steps (matched to 017.12), so curriculum arms have more wall steps by design — compare honestly against `A_joint@800` and `C@800`.

| Phase | What is trained | Program |
|---|---|---|
| **1** | discrete `ε` only | **force_seq** (same teacher as C) |
| **2** | unlock `π`; optionally keep learning `ε` | soft adm-gated mixture (grp available when adm allows) |

Eval always: hard argmax catalogue denotations + hard FIPS proxy + exact projective ray equality.

## 3. Arms

| Arm | Protocol |
|---|---|
| **A_cur** | phase1 force-seq ε → phase2 **joint** ε+π |
| **A_cur_freeze** | phase1 force-seq ε → phase2 **π only** (ε frozen) — tests whether recovered geometry + policy alone suffices |
| **A_joint** | single-phase A @ 800 (control; should ~match 017.12 A) |
| **B** | freeze true ε*, learn π @ 800 |
| **C** | learn discrete ε, force seq @ 800 |
| **Oracle** | true ε* + correct preferred branch |

## 4. Task / constants

Same native-structure task as 017.11/017.12: densest 16-vocab (58 FIPS edges, 39 seq≠grp), `r=e4`, holdout 0.35, seeds 0–2, topographo `SedenionAlgebra.mul`, Gumbel τ=1.0, LR 0.05.

## 5. Primary diagnostics

- Exact train/test success (mean±std over seeds)
- Adm edges before → after phase1 → after phase2; Jaccard vs true at each phase
- Catalogue idx match /16 after each phase
- Phase-2 branch frequencies (`grp`/`seq` choice fractions; soft `mean_w_grp`)
- Compare A_cur / A_cur_freeze vs A_joint (~0.035) and C (~0.37)

## 6. Success question

Does curriculum stabilize discrete A so held-out exact success rises **materially above ~0.035**?
