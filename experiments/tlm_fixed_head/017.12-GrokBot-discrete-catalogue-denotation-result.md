## 3. Strict native predicates

```text
Occ(e,r) = [e*r] if e*r ≠ 0 else undefined
Cyc(a,b) = [a*b] if (finite FIPS proxy) else undefined
P_seq(a,b,r) = Occ(a, Occ(b,r))
P_grp(a,b,r) = Occ(Cyc(a,b), r)   # masked unless Cyc-admissible
```

Native comparison: sign-insensitive projective ray equality.

**Relaxation (train only):** Gumbel-Softmax STE over catalogue; soft Cyc score gates the soft program mixture. Eval uses hard argmax denotations + hard proxy.

## 9. Failure analysis

**Verdict: mixed — discrete head unlocks hard FIPS reachability; primary arm A still fails held-out exact success.**

1. **Hard FIPS is now reachable.** Random/init catalogue selections already produce O(10) edges; learning moves the graph. This falsifies the continuous parameterization as the sole blocker identified in 017.10 §9.
2. **A does not unlock exact success** (~0.035 test). Joint STE learning of ε+π does not recover true `ε*` (index match mostly 0–4/16). Soft surrogate improves without inducing the correct legal OT trees.
3. **B unchanged** from 017.10 (~0.91 held-out): task remains well-posed when geometry is given.
4. **C ≫ A on both geometry recovery and exact metrics** under force-seq. Interpretation: preferred seq endpoints are an informative teacher for catalogue identity; the soft adm-gated mixture in A appears to dilute that signal (and/or STE noise prevents coordinated policy+denotation discovery).
5. **D** remains near floor; destroyed adm still prevents exploiting any recovered geometry.
6. Optional tau-anneal ablation (seed 0, 2000 steps, τ: 2→0.3) did **not** recover true indices for A (idx_match stayed 0; adm ~12) — schedule alone is not a free win.

Does **not** claim Issue 017 closed; does **not** claim modular grokking.

## 10. Recommended next GPT step

1. **Stabilize discrete A:** curriculum / two-phase train (first recover ε under force-seq or supervised catalogue CE on train pairs' implied rays, then unlock policy); or lower-variance discrete estimators (GS with lower τ only after warm-start; concrete STE without Gumbel noise).
2. **Diagnose A vs C gap:** quantify whether A's soft adm gate suppresses seq-driven catalogue recovery; ablate adm-log-barrier weight.
3. Only after a positive discrete-A exact result, attempt rigid external relation / modular stage (017.09 §4.2).
4. Owner may promote/close only after interpreting whether learned geometric admissibility contributes under a working discrete head; this filing does **not** close Issue 017.
