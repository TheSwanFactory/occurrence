## 2. Task and split construction

**Kind:** native-structure task from a **fixed hidden** OT-compatible denotation assignment `ε*` (not learned labels).

1. Vocabulary `D` with `|D|=16` token ids.
2. Fixed `ε*`: densest 16-subset of the 84 basic Events under the FIPS proxy (indices `[0,57,46,13,68,79,1,56,47,12,69,78,2,59,45,25]`).
3. Retained context `r = e4` (primary; see § r-sensitivity).
4. For each ordered pair `(i,j)` with a defined native program under `ε*`, target = preferred legal tree endpoint:
   - use **grp** when seq/grp both defined and disagree;
   - else **seq** (else grp if seq undefined).
5. Hold out ~35% of **pair combinations** (not repeats) for test. Held-out targets never enter denotation init or masks.
6. Learnable `ε_θ` starts from noise (arms A/C/D/E); arm B freezes to **true** `ε*`.

Per-seed materialized sizes (seed 0/1/2): train 149/143/152, test 75/81/72; always 58 true-admissible pairs and 39 disagree pairs on the full vocab graph.

**Oracle diagnostic** (not a trained arm): true `ε*` + correct preferred branch → exact train/test **1.0** on all seeds (task is well-posed).

## 3. Strict native predicates

```text
Occ(e,r) = [e*r] if e*r ≠ 0 else undefined
Cyc(a,b) = [a*b] if (finite FIPS proxy) else undefined
P_seq(a,b,r) = Occ(a, Occ(b,r))
P_grp(a,b,r) = Occ(Cyc(a,b), r)   # masked unless Cyc-admissible
```

Native comparison: sign-insensitive projective ray equality. No learned classifier as success criterion.

Training objective: mean `1 − |cos|` between soft program mixture and target ray (surrogate only).

## 8. Admissibility-graph diagnostics

- **True graph** within vocab: **58** directed FIPS edges (density ≈ 0.227); **39** of those have seq≠grp under `r=e4`.
- **Arm B:** graph before = after = true graph (58 edges); overlap with true = 1.0. Held-out success tracks use of this fixed graph + learned branch policy.
- **Arms A/C/D (learned continuous ε_θ):** admissibility edges **before = after = 0**. Soft adm scores rise (mean soft adm / \|cos\| often > 0.8), but the **hard** finite proxy is never hit. No task-relevant hard Cyc edge is created by learning.
- Denotation collapse: continuous arms kept 16 unique projective rays (no total collapse); they simply never land on catalogue rays.

## 9. Failure analysis (§8 decisive tests)

**Verdict on §8 decisive tests: mixed → overall negative for primary arm A; positive for “geometry matters when given” (B).**

1. **A does not generalize** under exact native success (0/0). Soft cosine improves (~0.81–0.94) without ever matching exact rays — surrogate ≠ native criterion.
2. **B ≫ A and C** on exact metrics: with true denotation geometry frozen, policy learning alone reaches ~0.91 held-out exact success. So the **task and OT program family are computationally usable** when ε is correct; learning continuous ε from noise is the failure point.
3. **D vs A** is uninformative at exact-0 for both (destroyed adm cannot be diagnosed when hard adm never appears). Soft losses are similar.
4. **Learned Cyc graph does not acquire task structure** under continuous Event-like parameterization: hard adm fraction stays 0.
5. **E/F** also fail exact ray match (F’s surrogate loss is low ≈ 0.02, showing continuous predictors can approximate directions without exact native endpoints).

**Why continuous ε_θ fails (precise):** the finite FIPS proxy requires `[a*b]` to coincide with a **catalogue** basic-Event ray. Unit pure-pair projections from unconstrained ℝ¹⁶ almost never hit that discrete locus, so `P_grp` stays masked and exact `P_seq` endpoints almost never equal the algebraic targets defined by `ε*`. Soft admissibility during training therefore optimizes a **relaxed geometry that does not induce exact OT program availability**. This establishes why the chosen continuous parameterization cannot demonstrate “learning makes grouped compositions available,” matching 017.09 §10’s allowed negative milestone.

Does **not** claim Issue 017 closed; does **not** claim modular grokking.
