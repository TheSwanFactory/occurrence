## 0. Fence

Configured experiment on the **finite** basic-Event / FIPS-style Cyc proxy. Not physical OT enactment, not modular grokking, not continuous certified locus `C`. Soft surrogates are not success criteria.

## 1. Motivation (from 017.10 §10.1)

Continuous ℝ¹⁶ Event-like `ε_θ` never hit the finite FIPS proxy: hard adm stayed **0** despite soft |cos| ~0.8–0.94. Recommended next step: a **discrete / catalogue denotation head** so hard FIPS edges are reachable; re-run A/C/D with **exact admissibility-graph change** as primary diagnostic.

## 2. Discrete head spec

For each vocab token, learn logits over the **84 basic-Event catalogue**.

| Phase | Denotation |
|---|---|
| **Train** | Gumbel-Softmax with `hard=True` (straight-through estimator): forward pass is discrete categorical selection; gradients flow through the soft Gumbel relaxation |
| **Eval** | `argmax` → hard catalogue vector |

Soft training surrogate remains mean `1 − |cos|` to the preferred native target ray. Reported metrics are **exact** projective ray equality under hard Cyc/FIPS proxy + hard `P_seq` / `P_grp`.

## 3. Task / arms / params

Same native-structure task as 017.10: densest 16-subset vocab (58 FIPS edges, 39 seq≠grp), `r=e4`, holdout ~35% of pair combinations, seeds 0–2.

| Arm | What is learned |
|---|---|
| **A** | discrete `ε_θ` + `π_φ` (primary) |
| **B** | freeze true `ε*`, learn `π` (sanity baseline) |
| **C** | discrete `ε_θ`, force `P_seq` |
| **D** | discrete `ε_θ` + `π` with shuffled/destroyed adm |
| **Oracle** | true `ε*` + correct preferred branch |

E/F omitted (not required for the discrete-head question). Steps 800, LR 0.05, Gumbel τ=1.0. Trainable params: A/D ≈ 2978 (16×84 logits + policy); B = 1634; C = 1344.

## 4. Primary diagnostics (new vs 017.10)

- `adm_edge_count_before` → `adm_edge_count_after`
- Jaccard / precision / recall of learned hard graph vs true FIPS subgraph
- Task-relevant disagree-edge count in learned graph
- Catalogue-index / ray recovery vs true `ε*`
- Exact train/test success

## 5. Success question

Does the discrete catalogue head unlock hard FIPS reachability **and** held-out exact success for primary arm A?
