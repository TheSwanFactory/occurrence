## 0. Fence

Configured experiment on the **finite** basic-Event / FIPS-style Cyc proxy. Not physical OT enactment, not modular grokking, not continuous certified locus `C`. Soft surrogates are not success criteria. Issue 017 **not** closed by this experiment alone.

**Anti-cheat:** held-out targets only for evaluation/ceiling; no target-aware preferred-tree / branch labels into training. **Rec_CE** is explicitly a **true-index teacher diagnostic** (uses true ε* catalogue indices; does **not** use held-out pair targets).

## 1. Motivation (from 017.16 §6)

Ceiling audit under freeze: recovered **H≈0.46** vs true-ε* **H=1.0**, with **H−A≈0.05**. Reachability dominates; further π tuning cannot close the missing ~0.54 at frozen imperfect denotations. Joint unlock reduces H. Next step is **catalogue-recovery / representation lift under freeze**, not another policy sweep.

## 2. Phase protocol

All primary recovery arms keep **ε frozen in phase 2** (π only).

| Phase | Rec_CE | Rec_ray | Baseline_freeze |
|---|---|---|---|
| **1** (N1=800) | CE toward **true** catalogue indices | CE toward **train-only** P_seq program-inverse vote argmax | force-seq projective loss on train targets |
| **2** (N2=800) | freeze ε, learn π | freeze ε, learn π | freeze ε, learn π |

Eval: hard argmax catalogue denotations + hard FIPS proxy + float projective ray equality. Ceiling H/A/S/G reuse 017.15 definitions (all examples in denominator).

## 3. Arms

| Arm | Protocol |
|---|---|
| **Rec_CE** | true-index CE teacher (diagnostic upper bound) → freeze π |
| **Rec_ray** | train-set P_seq inverse votes → CE (no `true_idx`, no held-out targets, no preferred-tree labels) → freeze π |
| **Baseline_freeze** | A_cur_freeze reproduction (force-seq → freeze π) |
| **B** | freeze true ε*, learn π @ 800 (sanity) |
| **ForceSeq_long** | optional control: force-seq for N1+N2=1600, then freeze π @ N2 |

## 4. Rec_ray supervision (documented)

1. Precompute all catalogue pairs `(c_a,c_b)` whose `P_seq=Occ(a,Occ(b,r))` endpoint matches a projective key.
2. For each **train** pair target only, cast unweighted votes for vocab tokens' catalogue indices over realizing pairs.
3. Phase-1 CE toward vote-argmax indices. No `task.true_idx`; no test targets; no preferred-tree labels.

## 5. Task / constants

Same native-structure task: densest 16-vocab (58 FIPS edges), `r=e4`, holdout 0.35, seeds 0–2, topographo `SedenionAlgebra.mul`, Gumbel τ=1.0, LR 0.05.

## 6. Primary metrics

- Test H, A, S, G (mean±std); catalogue idx match /16; Jaccard vs true adm graph
- ΔH vs Baseline_freeze; compare to B
- Ceiling audit on final frozen denotations

## 7. Success question

Does catalogue recovery raise **H** materially toward B under frozen ε?
